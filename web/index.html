Shadow Reign RPG

RPG de turno em Java Swing, rodando direto no navegador

O jogo roda como uma aplicação Java real dentro do navegador. O primeiro carregamento baixa cerca de 20 MB de runtime e leva alguns segundos — depois disso fica em cache.

Preparando…

WASD ou ↑←↓→ mover
Enter confirmar / interagir
Esc voltar / fugir da batalha
1 – 4 ações de combate e melhorias
Backspace apagar no nome
F3 ver hitboxes

Este jogo é controlado 100% por teclado, então não dá para jogar por toque. Abra esta página num computador — ou baixe o jogo.jar e rode com java -jar jogo.jar.
