Para o jogo rodar é necessário que as roots estejam marcadas corretamente, sendo elas:

src - sources
res - resources

vale ressaltar que o a pasta res deve estar em out (caso você use, caso não esteja automaticamente você deve copiar e colar)

Atenção! caso crie uma out automaticamente você deve apagar a criada depois para não haver duplicidade

[EN - ENGLISH]

For the game to run, the roots must be marked correctly, which are:

src - sources
res - resources

It is worth mentioning that the res folder must be in out (if you use it, if it is not automatically you must copy and paste)

Attention! If you create an out automatically you must delete the one created later to avoid duplication
